DAFFTECH PORTFOLIO FREE
=======================

Simple Portfolio Website Template

Terima kasih telah menggunakan DAFFTECH PORTFOLIO FREE.

Template ini dibuat untuk membantu Anda membuat website portfolio
sederhana tanpa perlu membuat website dari awal.


CARA MENGGUNAKAN
================

1. Buka file "index.html" menggunakan browser.

2. Untuk mengubah nama:
   Buka index.html lalu cari tulisan "Your Name".
   Ganti dengan nama Anda.

3. Untuk mengubah lokasi:
   Cari "Your City" lalu ganti dengan lokasi Anda.

4. Untuk mengubah email:
   Cari "your@email.com" lalu ganti dengan email Anda.

5. Untuk mengganti foto profile:
   Masuk ke folder "images".

   Ganti file:
   profile.jpg

   Gunakan nama file yang sama agar gambar otomatis muncul.


MENGGANTI PROJECT
=================

Masuk ke folder:

images/

Kemudian ganti:

project-1.jpg
project-2.jpg
project-3.jpg

Anda dapat menggunakan gambar project Anda sendiri.

Jangan mengubah nama file jika belum mengubah bagian
"src" pada index.html.


MENGUBAH INFORMASI PROJECT
==========================

Buka:

index.html

Cari bagian:

Project One
Project Two
Project Three

Kemudian ganti dengan nama project Anda.

Anda juga dapat mengubah:

- Kategori project
- Deskripsi project
- Link project


MENGUBAH SKILLS
===============

Buka:

index.html

Cari bagian "MY SKILLS".

Anda dapat mengganti:

HTML
CSS
JavaScript
Graphic Design

sesuai dengan kemampuan Anda.


MENGUBAH SOCIAL MEDIA
=====================

Di bagian footer index.html terdapat:

Instagram
TikTok
GitHub

Ganti tanda "#" pada link dengan link social media Anda.

Contoh:

<a href="https://instagram.com/username">

=============

images/project-3.jpg
