FAQ

Pertanyaan yang paling sering masuk sebelum pembelian.

01 Bagaimana cara mendapatkan file setelah membeli?

Pembayaran dan pengunduhan file dilakukan di halaman toko DAFFTECH di Lynk.id. Setelah pembayaran berhasil, file bisa langsung diunduh.

02 Metode pembayaran apa yang tersedia?

Transaksi diproses oleh Lynk.id sehingga pembayaran tercatat dengan aman. Pilihan metode pembayaran ditampilkan di halaman checkout.

03 Apakah ada produk gratis?

Ada. Portfolio Template tersedia gratis sebagai produk pembuka. Paket 5 template dan produk lainnya berbayar.

04 Apakah file bisa diedit dan dipakai offline?

Bisa. Semua template memakai HTML, CSS, dan JavaScript tanpa framework, sehingga mudah diedit bahkan untuk pemula. File cukup dibuka lewat browser dan bisa berjalan offline.

05 Apakah file boleh dijual ulang?

Tidak boleh. Kamu bebas mengedit dan memakai file untuk website sendiri, tetapi dilarang menjual ulang, membagikan gratis, atau mengunggah ulang file untuk distribusi.

06 Apakah DAFFTECH menerima pengerjaan website kustom?

Ya. Kami menerima proyek terpilih di luar koleksi produk. Kirim detail kebutuhan lewat formulir kontak atau email hello@dafftech.id.
