Beranda / Produk / Portfolio Template

Halaman portfolio yang langsung tayang.

Satu halaman berisi profil, karya, dan kontak. File mentah HTML, CSS, dan JavaScript tanpa framework, jadi kamu tahu persis apa yang dijalankan browser — tanpa build tool, tanpa dependensi.

Template DAFFTECH-PORTOFOLIO-FREE.zip

Isi halaman

Ada tiga bagian utama: blok profil singkat dengan foto dan tombol kontak, daftar proyek berisi tiga kartu bergambar, serta bagian akhir berisi email dan tautan media sosial.

Semua teks di dalamnya adalah contoh. Ganti dengan datamu sendiri: nama, deskripsi singkat, judul proyek, dan tautan hasil kerjamu.

Cara memakai

Unduh filenya, lalu buka index.html di browser — langsung tampil, tidak perlu server.

Edit teks dan gambar memakai editor teks apa pun (VS Code, Notepad++, bahkan Notepad). Kalau sudah cocok, unggah foldernya ke GitHub Pages, Netlify, atau hosting apa pun yang kamu punya.

Catatan jujur

Gambar proyek di dalam paket adalah foto contoh bukan hasil karyamu. Ganti sebelum dipakai demi kredibilitas — pengunjung bisa mencarinya di internet.

Template ini gratis selamanya. Tidak ada batas penggunaan untuk situs pribadimu, tetapi file mentahnya tidak boleh dijual ulang.
