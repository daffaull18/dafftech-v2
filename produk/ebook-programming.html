Delapan bab, dari pengenalan sampai terbit

Bab 1 menjelaskan cara kerja internet, browser, dan tiga bahasa dasar web beserta domain dan hosting. Bab 2 sampai 4 membahas HTML, CSS (termasuk Flexbox), dan JavaScript dengan contoh tag yang paling sering dipakai.

Bab 5 adalah proyek praktik: menyusun landing page sederhana dari kerangka HTML sampai sentuhan JavaScript. Bab 6 memandu menerbitkan website gratis lewat GitHub Pages, bab 7 memberi arah belajar selanjutnya, dan bab 8 berisi kunci jawaban seluruh latihan.

Format yang kamu terima

PDF 12 halaman untuk dibaca santai, plus versi HTML lengkap dengan CSS-nya bila kamu lebih suka membaca di browser atau ingin mencari teks tertentu dengan cepat.

Catatan jujur

E-book ini padat dan langsung pada intinya — bukan buku setebal 200 halaman. Kalau kamu mencari teori ilmu komputer lengkap, ini bukan bukunya. Ini untuk yang ingin cepat bisa membuat halaman web pertamanya.

Latihan di tiap bab tidak otomatis dinilai; kunci jawabannya ada di bab 8 untuk kamu periksa sendiri.
